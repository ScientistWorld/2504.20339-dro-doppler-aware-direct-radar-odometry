# Constraints

Future improvements must use the same benchmark and prediction contract for the existing score groups:

- Dataset: `data/synthetic_dro.npz` generated by `data/synthetic_radar.py`.
- Scenarios: `structured` and `tunnel`, with the same frame count, radar grid, beam timing, chirp signs, noisy gyro measurements, and ground-truth trajectories.
- Outputs: prediction JSON files with `method`, per-scenario `trajectory`, `ground_truth`, and velocity columns in the same format written under `checkpoints/`.
- Evaluation: `scripts/evaluate.sh` must read prediction artifacts and call only code under `eval/`; it must not import from `method/` or regenerate predictions internally.
- Dependencies: use the packaged `environment/container.def` and `environment/setup.sh` unless adding a clearly documented new experiment.

Valid changes include improving dense radar registration, Doppler infill, optimization, robust weighting, local-map update, scan correction, and motion modeling within the same radar odometry setting.

Invalid shortcuts include using ground-truth poses or velocities at inference time, changing the generated test trajectories to easier cases, replacing odometry with supervised fitting to the ground truth, or reporting paper numbers instead of computed scores.
